# 脉络品牌图标

| 使用位置 | 图稿 | 适配方式 |
| --- | --- | --- |
| Core 导航顶栏、Edge「关于」等较大展示位 | [品牌主标](<../../../素材/品牌主标（Brand Mark · 标准版）.svg>) | 保留五条叶脉和交汇处的细节。 |
| 浏览器标签页、窗口小图标、Windows 通知区 | [极小尺寸适配标](<../../../素材/极小尺寸适配标（Favicon  Micro Mark · 16–32px 专用）.svg>) | 保留三条加粗的叶脉。系统放大托盘图标时仍使用这份图稿。 |

两份 SVG 的叶脉均为透明镂空。调整主题色时只改外形填色，保留遮罩、画布和留白比例。

Core 深绿顶栏使用薄荷色 `#B5E5CF`。浏览器标签栏在浅色模式使用 `#175F4E`，深色模式使用 `#B5E5CF`。常规路径 `/favicon.ico` 提供 16、20、24、32、40、48 和 64 像素的小标。
