# 脉络 1.0.0

[English](1.0.0.md) · 简体中文

首个公开版本支持在新聊天中找回项目决定、当时的依据和对应版本的原件。Core 保存共享资料，每台 Windows 设备使用 Edge 配对，并按管理员授予的项目范围和读写权限访问。

| 下载 | 用途 |
| --- | --- |
| [Windows x64 安装包](https://github.com/Yafeiml/nodikarta/releases/download/v1.0.0/Nodicarta-Edge-1.0.0-win-x64-setup.exe) | 为当前 Windows 用户安装 Edge。 |
| `ghcr.io/yafeiml/nodikarta-core:1.0.0` | 在 Linux amd64 上使用 Docker Compose 和 PostgreSQL 运行 Core。 |
| [Core 离线镜像包](https://github.com/Yafeiml/nodikarta/releases/download/v1.0.0/nodikarta-core-1.0.0-linux-amd64.tar.gz) | 将同一预构建镜像传到离线主机，再用 `docker load -i` 导入。 |

首次使用请按[中文安装与配对说明](../../README.zh-CN.md)操作。Core 默认监听回环地址。从其他电脑访问、复用已有 PostgreSQL 和备份的方法见[部署指南](../../deploy/public/README.zh-CN.md)。

如需锁定本次实测的仓库镜像，可在部署目录的 `.env` 中设置 `NODICARTA_CORE_IMAGE=ghcr.io/yafeiml/nodikarta-core@sha256:35e8d8652961124712974f7b0554b838753fbd15e61c176ba03497aec1dec4f4`。

**在 Windows 上**，Edge 可在用户登录后静默进入通知区域。点击托盘图标即可打开主窗口。应用更新和本机已安装的 Skills 有各自的开关。

**对于维护者**，稳定更新渠道由 `nodicarta-edge-stable-win-x64.json` 及其独立的 `.sig` 签名文件组成。客户端用发行公钥验证清单，再按清单中的 SHA-256 校验安装包。[首版源码](https://github.com/Yafeiml/nodikarta/tree/v1.0.0)采用 MIT 许可证。
