# Nodicarta 1.0.0

English · [简体中文](1.0.0.zh-CN.md)

This first public release lets a new AI chat recover a project's decisions, supporting evidence and original attachments. Core stores the shared records. Each Windows device pairs through Edge and uses only the projects and permissions granted to it.

| Download | Use |
| --- | --- |
| [Windows x64 installer](https://github.com/Yafeiml/nodikarta/releases/download/v1.0.0/Nodicarta-Edge-1.0.0-win-x64-setup.exe) | Install Edge for the current Windows user. |
| `ghcr.io/yafeiml/nodikarta-core:1.0.0` | Run Core on Linux amd64 with Docker Compose and PostgreSQL. |
| [Core image archive](https://github.com/Yafeiml/nodikarta/releases/download/v1.0.0/nodikarta-core-1.0.0-linux-amd64.tar.gz) | Transfer the same prebuilt image to an offline host, then import it with `docker load -i`. |

Windows may show **Unknown publisher** on first install. This release uses a signed update manifest and ships the installer without a Windows Authenticode certificate. To verify a manual download, run `Get-FileHash .\Nodicarta-Edge-1.0.0-win-x64-setup.exe -Algorithm SHA256` and compare it with [SHA256SUMS.txt](https://github.com/Yafeiml/nodikarta/releases/download/v1.0.0/SHA256SUMS.txt).

Start with the [installation and pairing instructions](../../README.md#quick-start). The default server listens on loopback. The [deployment guide](../../deploy/public/README.md) covers access from another computer, existing PostgreSQL databases and backups.

To pin the exact registry image, set `NODICARTA_CORE_IMAGE=ghcr.io/yafeiml/nodikarta-core@sha256:35e8d8652961124712974f7b0554b838753fbd15e61c176ba03497aec1dec4f4` in the deployment's `.env`.

**On Windows**, Edge can start in the notification area when you sign in. Open its tray icon to show the window. The app's update setting controls the Edge application. The separate Skills preference controls updates to the Skills installed on your machine.

**For maintainers**, the stable update channel consists of `nodicarta-edge-stable-win-x64.json` and its detached `.sig` file. The client verifies the manifest with the release public key and checks the installer against its recorded SHA-256 digest.
